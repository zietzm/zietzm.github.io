Kelly Criterion Calculator

Compare true probability (p) and market implied probability (p') in percent form to compute Kelly sizing.

Formula used (binary market):
Long if p > p': f = (p - p') / (1 - p')
Short if p < p': f = (p - p') / p'

This comes from the standard Kelly setup for a binary payoff: first compute optimal long size on one side, and when edge is negative, compute Kelly on the complementary side and report it as a short with the same magnitude. See Kelly criterion (Wikipedia).
